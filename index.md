# suppoRt

Last updated: 2025-02-10

## Overview

**suppoRt** is a growing collection of various support functions for
`R`.

## Installation

To install **suppoRt**, please use:

``` r

# install.packages("remotes")
remotes::install_github("mhesselbarth/suppoRt")
```
